### Why Dual License?
We provide both licenses to ensure maximum compatibility with different project requirements, especially for game developers who may need the specific permissions granted by the OGA-BY license regarding technical distribution.

### How it works
Think of this as the narrative equivalent of Kevin MacLeod’s music terms: **you are completely free to use or adapt these stories—even under a proprietary license for commercial projects**—as long as you give proper credit. 

If you use or modify this work, you must state that it was originally created by **Stormwindsky** and provide a link to the license you chose.
